# Página de Error 404

Página web personalizada para mostrar un mensaje de error cuando una ruta no existe.

## Descripción

Este proyecto reemplaza una página de error básica por una versión visual más clara y personalizada. Incluye un mensaje de error, una imagen temática y un enlace para volver atrás .

## Características

- Mensaje de error 404
- Imagen temática
- Enlace para volver atrás
- Diseño simple y directo

## Tecnologías utilizadas

- HTML5
- CSS3
- GitHub Pages

## Objetivo

Practicar la creación de una página de error personalizada para mejorar la experiencia del usuario dentro de un sitio web.
